BEHIND THE RESULT

🧠 How was this calculated?

If a student attends every upcoming class, both the number of classes attended and the total number of classes increase.

(Attended + x) / (Held + x) ≥ 0.75

Here, x represents the minimum number of consecutive future classes that must be attended.

💡

Whole-class rule: Math.ceil() rounds the result upward because a student cannot attend a fraction of a class.
